New skill: frontend-vibe. Run it before building a frontend. It interviews you about the feel one question at a time, plays it back as a short brief, picks 2 or 3 design systems, libraries or effects from a checked catalog (Geist, Kumo, shadcn/ui, Paper Shaders, ShaderGradient, Canvas UI and more), and writes a build note a coding agent can follow.
