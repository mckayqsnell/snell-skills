First release as snell-skills. Install with `npx skills add mckayqsnell/snell-skills` or as a Claude Code plugin from the snell-skills marketplace. Includes the learning-doc skill (with the /learning-pdf command and a session-start offer) and the to-markdown skill. The learning-doc folder now comes from `LEARNING_DOC_DIR` in a `local.env` file instead of a hard-coded path.
